# TIMETABLE_AI — Smart Timetable Management System

A full-stack academic timetable management application built using Java, Spring Boot, Firebase Firestore, HTML, CSS, and JavaScript.

## Live Demo

https://timetable-ai-6dc00.web.app

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Java, Spring Boot, REST APIs
- **Database:** Firebase Firestore
- **Deployment:** Firebase Hosting, Render
- **Version Control:** Git, GitHub

## Key Features

- Student management
- Teacher management
- Course management
- Classroom management
- Timetable creation and management
- Scheduling conflict detection
- Automatic timetable generation
- Weekly timetable visualization
- CSV export
- Dashboard
